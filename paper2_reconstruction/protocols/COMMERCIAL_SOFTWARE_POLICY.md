# Commercial software policy

**DRAFT — NOT FROZEN**

Study-specific commercial software purchase equals zero. Do not use SAS, SPSS,
Stata, MATLAB, proprietary modules, paid institutional entitlements or trials
that cannot be replicated by a reader under the policy. Do not buy a licence.

A named commercial application is not automatic failure. Implement a sufficiently
specified, software-independent method using free/open-source tools; record
library versions and observable assumptions. Essential unreconstructable
proprietary function = F02; required unavailable version = F03; underspecified
procedure = the applicable specification code, not automatically F02.

Dependencies must be vetted as general-purpose tools, pinned with hashes and
licences, and must not contain the paper's original implementation. The same
dependency policy applies to every run. Agent/API costs, computing costs and
journal APCs are distinct from software purchase; report actual usage or unknown.
This draft does not authorize a new paid resource commitment.
